CHINMAY — BCA STUDENT PORTFOLIO
================================

FILES
-----
index.html       Website sections and content
style.css        Dark responsive design and visual styling
script.js        Mobile menu, typing animation, section highlighting, contact form
images/chinmay.jpg  Your uploaded profile photo

HOW TO RUN
----------
1. Download and extract CHINMAY_BCA_STUDENT_PORTFOLIO.zip.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
4. For editing, open the folder in Visual Studio Code. You can use Live Server.

CUSTOMIZE BEFORE SUBMISSION
---------------------------
- Update your email in script.js: replace YOUR_EMAIL@example.com.
- Change skill percentages to your real skill levels.
- Update project descriptions according to the actual work you completed.

CONTACT FORM
------------
This is a front-end demo. The form opens the visitor's default email application
using a mailto link. It does not send or store messages on a server. Direct form
submission needs a backend or a form service.

Built with HTML, CSS, and JavaScript. Google Fonts is optional; fallback fonts
are included if the external font cannot be loaded.
